Parte 2 · De LLM a agente

Un agente de deep research se entrena con las mismas tres etapas, ahora con herramientas

1 · Preentrenamiento agéntico

Trayectorias de agente mezcladas con texto general, para que el modelo base ya sepa buscar.

2 · Ajuste fino

Imitar trayectorias de un modelo maestro, filtradas: solo las que llegan bien y con buen formato.

3 · Refuerzo

el juez

Recompensa por respuesta correcta; para reportes abiertos, rúbricas que evolucionan (DR Tulu).
