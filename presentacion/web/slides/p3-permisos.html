38 · Anthropic (2025), Claude Code: configuración de permisos · Model Context Protocol (2024)

La tercera pieza, y para una clínica quizás la más importante: los permisos. En un archivo de configuración se escribe qué puede hacer el agente sin preguntar, por ejemplo buscar o leer, y qué no puede hacer nunca, por ejemplo borrar archivos o abrir la carpeta de datos de pacientes. Las herramientas nuevas se conectan con un estándar abierto que se llama MCP: Zotero, una base de datos, el correo.
