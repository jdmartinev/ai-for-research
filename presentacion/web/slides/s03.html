Su único trabajo: dar una probabilidad a cada token posible

5 · IA para la investigación

Y con esos tokens, ¿qué hace el modelo? Una sola cosa: predice el siguiente. Le doy «Durante la fase de apoyo de la marcha, la rodilla…» y me devuelve una probabilidad para cada token posible. Fíjense que no devuelve una respuesta: devuelve una distribución. Esto es importante para nosotros como investigadores: el modelo no es una base de datos. Si no le damos la fuente, escribe lo que un texto así probablemente diría, sea cierto o no.
