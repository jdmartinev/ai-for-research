3 · IA para la investigación

El encuadre de Karpathy: un modelo es dos archivos, los pesos y un programa corto que los ejecuta. Su único trabajo es predecir el siguiente token. Los tokens son fragmentos, no palabras: un término raro de tu campo se parte en varios pedazos. Muestra las probabilidades reales de un modelo pequeño para una frase de biomecánica. Idea clave: no es una base de datos; si no le das la fuente, genera lo que un paper "probablemente diría".
