9 · IA para la investigación

El patrón ReAct: un modelo de lenguaje en un ciclo con herramientas. Lo que cambia frente al chat es que el resultado de cada herramienta vuelve al modelo como retroalimentación: el error de un script, el contenido de un archivo, una búsqueda. Ese es el juez de esta parte.
