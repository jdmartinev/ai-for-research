Parte 2 · De LLM a agente

Un agente cierra el ciclo con el mundo: las herramientas le responden

Juez · las herramientas

28 · Yao et al. (2023), ReAct

Eso, en ciclo, es un agente: observar, pensar, actuar y ver el resultado. Y aquí el juez son las herramientas. Si el código falla, el error vuelve al modelo. Si la búsqueda no encuentra nada, eso también vuelve. Cada resultado es el juez del paso siguiente.
